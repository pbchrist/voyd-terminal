# Voyd Story Room Lore Authority

This directory is the single lore entrypoint for Story Room v3.

## Authority order

1. `canon/CORE_LAWS.md` — compact governing laws for generation and validation.
2. `canon/voyd_mythography.md` — Patrick-approved Voyd canon synthesis; wins over conflicting summaries.
3. `universe/` — distilled Gate of Nyandor setting, characters, themes, history, magic, and timestream material.
4. `canon/canon_events.json` — historical examples and evidence, not a scene pantry.
5. `book_maps/` — navigation aids into the novels.
6. `raw_sources.json` — immutable full-book source locations and hashes; evidence-only fallback.

## Generation rule

Lore supplies physics, causal possibility, history, and constraints. It does not supply prose to imitate.

Story Room must prefer universe laws over replaying book events. Raw-book passages are retrieved only when a factual question cannot be resolved from the distilled corpus, and book wording must not be reused as generated scene prose.

Terminal story canon may invent new cats, events, institutions, objects, and consequences when they obey source canon. Source canon is never silently rewritten.
